🛍️ Project Name

DigiTools Platform

📌 Description

This is a modern and responsive e-commerce frontend application built using React. Users can browse products, add them to the cart, and manage their selections with a smooth and interactive UI. The project focuses on clean design, state management, and user-friendly interactions.

⚙️ Technologies Used
React.js
Tailwind CSS
DaisyUI
JavaScript (ES6+)
JSON (for product data)
🚀 Features
🧭 Navbar
Designed based on Figma
Displays cart icon
Shows total product count dynamically
🎯 Banner Section
Includes heading, description, and image
Call-to-action buttons
📊 Stats Section
Styled according to Figma design
🔄 Main Section & Toggling
Two buttons: Cart and Product
Product section is visible by default
Cart section shows empty message initially
Toggle between Cart and Product views
